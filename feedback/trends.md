# 2026年6月 タクシードライバー業界トレンド分析

## 今週のXトレンド

1. **2026年4月運賃改定の影響拡大** - 東京23区で初乗り1キロが500円に引き上げられ、最大60万円の年収増加可能性が報道されている
2. **求人倍率9.11倍の過去最高水準** - 令和6年度全国平均で求人倍率が9倍超となり、転職希望者が極めて有利な売り手市場が形成されている
3. **入社祝い金の競争激化** - 10万〜50万円の高額入社祝い金を提示する企業が増加し、人材確保競争が加速している
4. **GO Crewなど柔軟な働き方の普及** - アプリ専用のパートタイムドライバー（GO Crew）が週3日からの勤務で時給1,500〜1,875円を提供し、新しい労働モデルが広がりつつある
5. **年齢不問の転職市場形成** - 40代・50代からの転職者が増加し、タクシー業界の「年齢の壁」が実質的に消滅している

## 求人市場トレンド

### 深刻な人手不足の継続
- ドライバーの平均年齢が約59歳に達し、60歳以上が全体の半数近くを占める高齢化が進行
- 過去10年間で30代以下の新規就業者が約40%減少している
- コロナ禍で他業種に転職したドライバーの大半が戻らず、構造的な人手不足が形成されている

### 採用企業の対策の進化
- 未経験者向けの充実した研修制度が標準化
- 二種免許取得費用の全額・部分支援が増加
- GOアプリなどのデジタル化により、フルタイム以外の働き方が充実

### 賃金格差の課題
- 平均年収502万円（東京）で、全産業平均644万円との142万円のギャップ存在
- 入社祝い金や運賃改定により一時的な改善傾向を見せるも、構造的な改善には至っていない

### 外国人材の正式化
- 2024年3月から特定技能制度に「運送業」分野が追加され、外国人ドライバーの正規雇用が可能化
