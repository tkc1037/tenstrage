## スレッド

### 1/2

```
★歩合率の1%は年収12万の差になる★

タクシーの給料は基本「売上×歩合率」で決まる。
この歩合率、会社によって全然違う。

例えば月の売上が100万だとして
歩合60%→支給額60万
歩合61%→支給額61万
```

### 2/2

```
たった1%で月1万、年間で12万変わる。
しかもこの差は毎月・毎年ずっと続く。
3年で36万。5年で60万。

会社選びで「雰囲気が良さそう」だけで決めると
この差に気づかないまま何年も過ぎる。

歩合率は面接で聞ける。聞かない理由がない。
```
