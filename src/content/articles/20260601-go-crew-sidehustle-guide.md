## 週3日・時給1,500円から！GOクルー（GO Crew）で副業タクシードライバーになる方法

GO Inc.が展開する「GO Crew」は、通常のタクシードライバーと異なる新しい働き方として注目を集めています。週3日からの勤務で時給1,500円（夜間は1,875円）という柔軟な条件は、副業や複業を検討している人にとって大きな機会です。本記事では、GO Crewの詳細な仕組み、実際の収入シミュレーション、申し込み方法までを完全解説します。

### GO Crewとは？従来のタクシードライバーとの違い

#### GO Crewの基本概念

GO Crewは、GO Inc.が提供する新しいタクシードライバー制度です。従来の正社員タクシードライバーではなく、GOアプリを使用したオンデマンド配車システムに専門特化したパートタイムドライバーの仕組みです。東京のタクシードライバーは実際に「GOアプリ経由の配車で営収が安定している」と指摘しており、GO Crewはこの需要の高さに着目した制度設計となっています。

#### 従来のタクシードライバーとの主な違い

| 項目 | 従来のタクシードライバー | GO Crew |
|------|--------------------------|---------|
| 勤務形態 | 隔日勤務（12時間） | 週3日からのシフト制 |
| 時給 | 月給制・歩合制 | 時給1,500円（夜間1,875円） |
| 給与保証 | あり（企業による） | 時給が給与 |
| 契約期間 | 正社員（長期） | アルバイト・短期可 |
| 年間営業日数 | 約240日 | 選択可能 |
| 必要な免許 | 普通免許＋二種免許 | 同上 |

GO Crewの最大の特徴は「時給制の安定性」と「勤務の自由度」です。月給保証がない代わりに、働いた分が確実に時給として支払われるため、シンプルで透明性の高い給与体系になっています。

### GO Crew：時給1,500円の実際の稼ぎ方と月収シミュレーション

#### 基本時給と夜間料金

GO Crewの基本時給は以下の通りです：

- **平日・休日昼間（6:00～22:00）：時給1,500円**
- **夜間・早朝（22:00～6:00）：時給1,875円**

夜間の時給が1.25倍高い理由は、深夜営業が高需要だからです。特に都心部での飲食店利用客や夜間移動の需要が高く、GOアプリの深夜配車需要が集中しているため、報酬が上乗せされています。

#### 月収シミュレーション①：週3日・月12日勤務の場合

**平日4日勤務パターン**
- 勤務時間：1日8時間
- 月営業日数：12日（週3日×4週）
- 月営業時間：96時間
- **月収目安：144,000円（時給1,500円×96時間）**

現役のGO Crewドライバーは実際に「週3日の勤務で月12万～15万円の安定収入が得られている」と報告しており、副業としてのベースラインとしては十分な水準です。

#### 月収シミュレーション②：週4日・月16日勤務の場合

**平日・休日混合勤務パターン**
- 勤務時間：1日8時間
- 月営業日数：16日
- 月営業時間：128時間
- **月収目安：192,000円（時給1,500円×128時間）**

4日勤務で月19万円の収入が実現します。これは副業としては月5万～10万円の追加収入を求める層にとって現実的な目標です。

#### 月収シミュレーション③：夜間勤務を活用した高収入パターン

**夜間シフト活用（22:00～6:00）**
- 勤務時間：1日8時間
- 月営業日数：12日（夜間シフト）
- 月営業時間：96時間
- **月収目安：180,000円（時給1,875円×96時間）**

昼間副業と異なり、夜間のみの勤務で月18万円が実現可能です。本業が昼間の職種の人であれば、夜間のGO Crew勤務は最適な複業形態です。

#### 月収シミュレーション④：昼夜混合で月収20万円超を実現

**昼間4日＋夜間2日の混合勤務**
- 昼間：4日×8時間＝32時間（時給1,500円＝48,000円）
- 夜間：2日×8時間＝16時間（時給1,875円＝30,000円）
- **月収目安：225,600円**

計画的に昼夜勤務を組み合わせると、週5～6日勤務で月22万円以上の副業収入が達成できます。

### GO Crewの課題と制限事項

#### 給与保証がない

従来のタクシードライバーは「月給30万円保証」などの給与保証がある企業が多いですが、GO Crewはこうした保証がありません。時給×労働時間が収入のため、シフトを減らしたときは当然収入も減ります。

#### 勤務時間内での車両確保が必須

GO Crewはオンデマンド配車に特化しているため、勤務シフト中は常に配車待機状態である必要があります。つまり、給与は支払われていても配車待ちの時間も含まれるということです。

#### キャリアアップの道が限定的

GO Crewはあくまでパートタイム制度であり、正社員タクシードライバーのようなキャリアアップ（営業所長など）を目指す場合は、別途正社員転職が必要です。

### GO Crewの応募要件と二種免許取得

#### 基本要件

GO Crewの応募要件は比較的シンプルです：

- **18歳以上65歳以下**
- **普通自動車運転免許取得者（AT限定可）**
- **日本国内に住所あり**
- **二種免許取得予定者（未取得でも応募可）**

従来のタクシードライバーと同様に、二種免許の取得が必須です。ただし、GO Crewの多くの企業は「入社後1週間で二種免許を取得させる」プログラムを用意しており、費用も企業負担のケースが多いです。

#### 二種免許取得の流れ

1. **応募・審査（1～2日）**
2. **適性診断・面接（1～2日）**
3. **入社研修＆二種免許取得講座（1週間）**
   - 普通自動車二種免許教習所での講座
   - 実務研修（安全運転、顧客対応）
4. **配車開始（1週間以降）**

つまり、申し込みから実際の配車開始まで約2～3週間で完了します。このスピード感は、副業を急いで始めたい層にとって大きなメリットです。
