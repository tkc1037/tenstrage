## GO Crewで稼ぐ新しい働き方：時給1,500～1,875円、時間選択制タクシードライバーの実態2026

2023年3月に開始したGO Crew（GOの時間選択制パートタイムドライバー制度）が、2026年現在で急速に普及しています。これまでのタクシー業界の「長時間拘束」というイメージを打ち破り、時間選択制・マイカー通勤・Wワーク可能という、全く新しい働き方が実現しました。時給1,500～1,875円という競争力ある時給で、副業層や時間に制約ある層からの注目が集まっています。このガイドでは、GO Crewの実態を詳しく解説し、実際にいくら稼げるのか、どんな人に適しているのか、を具体的に説明します。

### GO Crewとは：タクシー業界の働き方革命

#### GO Crewの基本スペック

GO Crewは、GO Inc.（ゴー）が提供する配車アプリ「GO」専用のパートタイムドライバー制度です。2026年6月現在、以下のような特徴があります。

**基本的な定義**：
- GO独占の配車アプリ利用
- 時間選択制（1日2時間～選択可能）
- マイカー通勤（会社配車ではなく自分の車で営業）
- フルタイム雇用ではなく業務委託に近い形式
- 東京都内の主要エリアで展開中

**登録者数の推移**：
- 2023年3月開始時：500～800人
- 2024年6月時点：3,000～5,000人
- 2026年6月現在：15,000～20,000人（推定）

GO Crewの急速な普及は、タクシー業界の人手不足とドライバーのニーズが合致した結果です。東京の現役ドライバーは実際に「GO Crewなら副業でもできるし、自分のペースで稼げる」と評価しています。

#### フルタイムドライバーとの違い

GO Crew（パートタイム）とフルタイムドライバーの主な違いは以下の通りです。

| 項目 | GO Crew | フルタイムドライバー |
|------|---------|-------------------|
| 労働形態 | 時間選択制・業務委託に近い | 雇用契約・隔日勤務が主流 |
| 営業車両 | マイカー（ガソリン代は自己負担） | 会社配車（会社負担） |
| 営業時間 | 1日2～12時間を自由選択 | 隔日勤務（昼12時間+深夜12時間など） |
| 給与方式 | 営収歩合制（時給換算1,500～1,875円） | 月給制＋歩合給（月収30～60万円） |
| Wワーク | 可能 | ほぼ不可（拘束時間長） |
| 入社祝い金 | 10～20万円（相対的に低い） | 30～50万円 |
| 給与保証 | なし | あり（月20～35万円） |
| ボーナス | なし | あり（年2～3回） |
| 研修 | 簡易的（1日～3日） | 充実（1～2週間） |
| 二種免許支援 | なし（自己負担） | 全額支援 | あり |

東京のベテランドライバーは「GO Crewは副業向け、フルタイムは本業向け。ライフスタイルで選ぶべき」と指摘しています。

### GO Crewの時給実績：1,500～1,875円は実際に稼げるのか

#### 公式発表の時給と実際の稼ぎの乖離

GO Inc.は「GO Crewドライバーの時給1,500～1,875円」を謳っていますが、実際はどうでしょうか。

**公式データ**：
- 公式サイト掲載の「平均時給」：1,500～1,875円
- サンプル対象：GO Crew登録ドライバー全体
- 観測期間：2026年3月～5月（最新データ）

**実際のドライバーの報告**：
- 朝7時～11時（都心営業）：時給1,800～2,000円（朝の通勤ラッシュは高効率）
- 昼11時～15時（低需要時間帯）：時給1,200～1,500円（ビジネス利用層が少ない）
- 夜間18時～23時（繁忙時間帯）：時給1,600～1,900円
- 深夜24時～翌5時（タクシー専業層との競争）：時給1,200～1,400円

つまり、営業時間帯によって時給は大きく変動するのです。GO Inc.の「1,500～1,875円」は、効率的な営業時間帯を選んだドライバーの平均であり、全ての時間帯で同じ時給が実現できるわけではありません。

### GO Crewが適している人の特性

#### パターン1：副業で稼ぎたい会社員

会社員をしながら、副業でさらに稼ぎたいというニーズに完全にマッチします。

**メリット**：
- 朝2～3時間や夕方2～3時間のみの営業で月10～15万円の追加収入
- 営業スケジュールを完全に自由設定できるため、本業との両立が簡単
- 年間100～180万円の追加収入が期待できる

**事例の相場**：
- 朝専門（7時～10時、3時間 × 20日）：月営収54,000円
- 夕方～夜間専門（17時～20時、3時間 × 20日）：月営収48,000円
- 副業年収：72万円～86.4万円

**注意点**：
- 会社の副業禁止規定がないか確認が必須
- ガソリン代・メンテナンス費用は自己負担（月5,000～10,000円）
- 税務申告が必要（副業収入が年20万円超の場合）

#### パターン2：Wワークで家計を支えたい非正規層

シングルマザーや家計の補助が必要な層にとって、柔軟な働き方は重要です。

**メリット**：
- 子どもの学校送迎前後の営業が可能
- 週3～4日の営業で月15～20万円が期待できる
- 保育施設の営業時間に合わせた営業スケジュール調整が可能

**実績例**：
- 朝6時～9時（3時間）+ 夕方15時～18時（3時間）、週4日営業
- 日営収：9,600円～11,000円
- 月営収（週4日 × 4週）：154,000～176,000円
- 年間営収：約185万～211万円

**注意点**：
- ガソリン代・メンテナンス費用で月5～10%のコスト削減が必要
- 雇用保険・厚生年金の加入がないため、自分で手配が必要
- 交通事故のリスク対応（自動車保険で確認）

#### パターン3：セミリタイア層や年金生活者

年金だけでは足りない層が、無理のないペースで追加収入を得られます。

**メリット**：

**実績例**：

- 時給1,600円（夜間営業で安定的な時給）
- 月営収：153,600円
- 年間営収：約184万円

**注意点**：
- 高齢者（70代以上）はGO Crewの登録条件を確認すべき
- 健康診断・適性診断が必要な場合がある
- 保険加入（任意保険の確認）が重要

#### パターン4：タクシー業界での「試行ドライバー」

未経験者がタクシー業界の適性を試してから、フルタイム転職を検討する層。

**メリット**：
- 実際にタクシー営業を体験してから、フルタイム転職を決定できる

- 万が一向いなくても、GO Crewのみで継続できる

**実績例**：

**注意点**：

- フルタイム転職を視野に入れて、業界知識を積極的に学ぶ必要あり

### GO Crew登録から稼ぎまでの全フロー

#### 登録条件と必要な手続き

GO Crewの登録から営業開始までのフロー：

**Step 1：登録条件の確認（1日）**
- 年齢：21歳～65歳（実際には70代の登録者も存在）
- 普通免許保有：2年以上の運転経歴が必須
- タクシー二種免許：不要（普通免許のみでOK）
- マイカー保有：軽自動車からセダンまで対応

**Step 2：オンライン申込み（30分～1時間）**
- GO公式サイトの「ドライバー登録」ページからオンライン申込み
- 必要情報：氏名、住所、電話番号、メールアドレス、免許証番号
- 登録費用：無料

**Step 3：書類審査（1～3日）**
- 提出書類：運転免許証、身分確認書類、自動車検査証（車検が有効なもの）
- 審査内容：有免許者か、過去の交通違反歴がないか
- 審査手数料：無料

**Step 4：研修・説明会（1～3日）**
- 研修内容：GO Crewの説明、営業方法の基礎、保険・事故時の対応
- 研修場所：GO指定の研修会場（東京都内3ヶ所程度）
- 研修費用：無料
- 研修時間：2～4時間（短い）

**Step 5：アプリ登録・設定（30分）**
- GO運転者アプリをスマートフォンにインストール
- アプリ内で銀行口座情報、税務申告情報を登録
- テスト営業で基本機能を確認

**Step 6：営業開始（登録後3～7日）**
- 申込みから営業開始まで平均5～10日
- 最初は「低稼働」で様子見営業することが推奨される
- 営業開始から最初の報酬受け取りまで：約2～3週間

東京のGO Crewドライバーは「登録から営業開始まで驚くほど早い。フルタイムなら1ヶ月の研修期間があるが、GO Crewなら1週間で開始できる」と評価しています。

#### 実際の営業流れ：朝営業を例に

GO Crewで朝7時～11時に営業する場合の実際の流れ：

**6時50分：自宅出発**
- 営業開始30分前に出発
- 運転ルートの確認、ガソリンスタンド立ち寄り（必要に応じて）

**7時00分：営業エリアに到着、アプリON**
- GO運転者アプリを起動
- 営業エリアを選択（例：六本木、虎ノ門など）
- ステータスを「営業中」に設定

**7時～11時：配車依頼を受ける**
- スマートフォンのアプリに乗客の依頼が届く
- 依頼内容（乗車地点、下車地点、予想乗車時間）を確認
- 受け入れ/拒否を判断（拒否も可能）
- 乗客を迎えに行く

**乗車中：営業**
- 乗客を目的地に送迎
- 実際のタクシー営業と同じ
- 支払いはGOアプリ内で決済（乗客がアプリで支払い）

**下車後：次の依頼待ち**
- アプリが次の配車依頼を待機状態に設定
- 乗客がいない時間は実車待機

**11時00分：営業終了、アプリOFF**
- ステータスを「営業終了」に変更
- アプリをバックグラウンドに設定
- 自宅に帰宅またはその日の別業務に移行

**月1～2回：報酬確認・振込**
- GO運転者アプリで月間営収、手数料、振込金額を確認
- 毎月20日と月末日の2回、銀行口座に自動振込み
- 振込金額：営収 - GO手数料（10～15%） - 自動車保険料金

東京の現役ドライバーは「フルタイムなら隔日勤務で拘束時間20時間超。GO Crewなら4時間で自由。実にシンプル」と評価しています。

### GO Crewの手数料と実際の手取り計算

#### GO Crewの手数料体系

GO Crewドライバーが受け取る報酬は、営収から複数の手数料が差し引かれた金額です。

**営収から差し引かれる項目**：

1. **GO手数料：営収の10～15%**
   - 配車システム利用料
   - GO Crewドライバー向けは通常のフルタイムドライバーより低い傾向（手数料率を下げてGO Crewを普及させている）

2. **自動車保険料：月額5,000～10,000円（営収から自動控除される企業も、自己負担企業も存在）**
   - GO Crewドライバー向け専用保険が用意されている
   - 月定額制で、月営収に関わらず一定額

3. **ガソリン代：営収の15～20%程度を目安に自己計算**
   - 営収には含まれず、ドライバーが自己負担
   - 乗車距離により変動（市街地は20km/L、郊外は25km/L程度）

4. **自動車メンテナンス費用：月5,000～15,000円（自己負担）**
   - オイル交換、タイヤ交換、定期点検など
   - ドライバーが自分で手配

#### 実際の手取り計算例

月営収15万円のドライバーの手取り計算：

```
営収：150,000円

- GO手数料（12%）：18,000円
- 自動車保険料：7,000円
- ガソリン代（営収の18%）：27,000円
- メンテナンス費用（概算月額）：10,000円

手取り：150,000 - 18,000 - 7,000 - 27,000 - 10,000 = 88,000円

月営収150,000円 → 実手取り88,000円（58.7%）
```

フルタイムドライバーの月営収50万円と比較すると：

```
フルタイムドライバーの場合：
営収：500,000円

- 会社が給与保証、税金、保険を負担
- ドライバーの手取り：300,000～350,000円（歩合率60～70%）
- 会社が車両維持費、保険料を負担

月営収500,000円 → 実手取り300,000～350,000円（60～70%）
```

つまり、**GO Crewは実手取り率が50～60%程度で、フルタイムドライバーの60～70%より低い傾向があります**。これはGO Crewが「個人事業主に近い形式」であり、自分で維持費・税金を負担するためです。

### GO Crew vs フルタイムドライバー：どちらを選ぶべきか

#### 年収目標別の選択肢

**年収300万円未満を目指す場合：GO Crew推奨**
- GO Crew月営収10～15万円で年収120～180万円
- Wワークで月収20万円超なら年収240～300万円
- フルタイムより時間効率がいい

**年収300～500万円を目指す場合：相談**
- GO Crew単独では不可能（月営収25万円超が必要で、フルタイム同然になる）
- GO Crew + Wワークの組み合わせなら可能
- フルタイムドライバー単独でも可能

**年収500万円超を目指す場合：フルタイムドライバー推奨**
- GO Crew単独では時給効率の限界あり
- フルタイムドライバー + アプリ活用で800万円超も目指せる
- ボーナス、給与保証などの待遇がフルタイムが有利

#### ライフスタイル別の選択肢

| ライフスタイル | 推奨 | 理由 |
|-----------|------|------|
| 会社員を続けつつ副業 | GO Crew | 時間自由度が必要 |
| シングルマザー | GO Crew | 子育てと両立が必要 |
| セミリタイア層 | GO Crew | 適度な収入と自由時間が必要 |
| タクシー業界未経験者 | GO Crew→フルタイム | 試行期間を設けられる |
| 40～50代の転職 | フルタイム | 給与保証・待遇の充実が必要 |

東京の現役ドライバーは「GO Crewとフルタイムは同じタクシー営業だが、全く別の働き方。人生設計で選ぶべき」と指摘しています。

### GO Crewの報酬受け取り方法と税務申告

#### 報酬の支払い体系

GO Crewドライバーの報酬は、毎月20日と月末日の2回に分けて振込みされます。

**支払いフロー**：
1. 月間営業（1日～30日、または31日まで）
2. 月末日：営業集計
3. 翌月5日～10日：営収計算＆手数料差し引き
4. 翌月15日～20日：第1回振込み（月前半分の営収50%程度）
5. 翌月25日～末日：第2回振込み（月後半分の営収50%程度）

振込み口座は登録時に指定した銀行口座に自動振込みされます。

#### 税務申告（個人事業主扱い）

GO Crewドライバーは「個人事業主」扱いのため、税務申告が必要な場合があります。

**税務申告が必要な条件**：
- GO Crew営収が年20万円超（副業の場合）
- GO Crew営収が年65万円超（専業の場合）

**申告手続き**：
- 所得税：毎年2月15日～3月15日に確定申告
- 必要書類：GO Crewの営業記録、領収書、銀行振込記録
- 申告方法：税務署窓口またはオンライン申告（e-Tax）

**節税対策**：
- ガソリン代：領収書を保管（営業に直結する経費として控除可能）
- メンテナンス費用：請求書を保管
- 自動車保険料：経費として控除可能
- 通信費：スマートフォン通信料の一部

東京の税理士は「GO Crewドライバーは、ガソリンとメンテナンス費用をしっかり記録すれば、年15～20万円の節税が可能」とコメントしています。

### GO Crewで稼ぐための実践的なコツ

#### コツ1：営業時間帯の選択が最重要

時給1,500～1,875円を実現するには、需要が高い時間帯を選ぶことが最重要です。

**朝ラッシュ時間帯（7時～10時）**：
- 時給1,800～2,000円（最高効率）
- オフィス向け移動が多く、短距離乗車が頻発
- 1乗車あたり15分程度の短乗車が多い
- 推奨：朝のみ専門で月営収5～8万円を狙う

**昼間時間帯（11時～15時）**：
- 時給1,200～1,400円（低効率）
- ビジネス利用が減少、観光利用が微増
- 乗車数が少ないため避けるべき時間帯
- ただし、医療機関・官公庁エリアでは需要あり

**夕方～夜間時間帯（17時～23時）**：
- 時給1,500～1,800円（高効率）
- 退勤ラッシュ、飲食店利用者が増加
- 乗車距離が長めになるため、単価も高い
- 推奨：17時～21時に集中営業

**深夜時間帯（24時～5時）**：
- 時給1,200～1,400円（専業ドライバーとの競争あり）
- 酔客が多く、事故・トラブルリスク増加
- 初心者には非推奨

#### コツ2：営業エリア選定

営業時間帯と同等に重要なのが営業エリア選定です。

**高需要エリア**：
- 六本木・虎ノ門（ビジネス地区）：朝夕の利用率が高い
- 渋谷・新宿（繁華街）：夜間営業の需要が高い
- 東京駅周辺（交通ハブ）：昼夜通して需要あり
- 羽田空港近辺（空港関連）：利用距離が長く単価高い

**避けるべきエリア**：
- 住宅地（利用率が低い）
- 深夜の郊外（クルマ利用者が少ない）

#### コツ3：複数の配車アプリを併用

GO Crewはあくまで「GO専用」ですが、別途他のアプリ（Uber、S.RIDEなど）に登録することで、営業効率を向上させることが可能です。

**併用戦略**：
- GO：朝7時～11時（時給1,800円で集中営業）
- Uber：昼間11時～16時（利用層が異なり相互補完）
- GO：夕方17時～21時（夕方ラッシュで再度営業）

この戦略で、1日8時間営業で月営収25～30万円を実現することも可能です。

### GO Crew登録時の注意点とリスク

#### 注意点1：自動車維持費が想定より高い

GO Crew営業を開始してから「思った以上に維持費がかかる」という相談が多いです。

**実際の維持費**：
- ガソリン代：1日営業8時間で70km走行、月営業20日 = 1,400km = 約11,000円
- オイル交換：3,000km毎に交換必要 = 月約4,000円相当
- タイヤ交換：40,000km毎に交換 = 月1,000円程度（年12,000円÷12）
- 定期点検：3年車検で月約1,000円程度
- **月合計維持費：17,000円程度**

月営収15万円でも、手数料7,000円 + 維持費17,000円 = 24,000円が差し引かれ、実手取りは実質126,000円。手数料率が84%になるのです。

#### 注意点2：会社員の副業禁止規定との確認が必須

会社員がGO Crewで副業する場合、会社の副業禁止規定との衝突がリスクです。

**確認すべき事項**：
- 就業規則に「副業禁止」条項があるか
- 「タクシー運転」が具体的に禁止されているか
- 「給与以外の収入」に対する届け出が必要か

2026年現在、多くの企業で副業が容認されつつありますが、金融機関・公務員・特定職種では禁止されている企業も多いです。

#### 注意点3：交通事故・トラブルのリスク

GO Crew営業は、交通事故のリスクがあります。

**リスク対策**：
- 自動車保険の「運送業務用」に変更（通常の個人保険では対応不可能な場合がある）
- GO Crewが提供する「保険パッケージ」に加入
- 月額5,000～10,000円で事故対応、損害賠償を補償

事故が起きた場合、保険に入っていないと全額自己負担になり、月営収の数ヶ月分が失われる可能性があります。

### まとめ：GO Crewは「新しい働き方」として機能しているか

2026年現在、GO Crewは以下の層にとって「新しい働き方」として機能しています：

**メリットが大きい層**：
1. 副業で月10～15万円の追加収入を求める会社員
2. Wワークで家計を補助したいシングルマザー
3. セミリタイア層で月10～20万円の追加収入を求める層
4. タクシー業界を試行してから本格転職を検討する層

**メリットが限定的な層**：
1. 年収500万円超を目指す層（フルタイムドライバーが有利）
2. 長期的な生活保障を求める層（給与保証・ボーナスがないため）

東京の現役ドライバーは「GO Crewはタクシー業界の働き方を大きく変えた。時間自由度が必要な層には革命的な仕事」と評価しています。
